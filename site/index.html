Physical memory

Regions follow from the boot header and from where v86 puts things: setup at 0x80000, command line at 0x8e000, the 32-bit part always at 1 MiB. v86 does not expose the e820 map; SeaBIOS builds it from the RAM size, so it matches the bars below (usable RAM, with the 0x9fc00–0x100000 hole reserved).
